# Money Manager (v1)

> ⚠️ Legacy project — the actively developed version is **Money Manager 2.0**:
> https://github.com/AdamKuzniarski/money-manager-2.0

Money Manager (v1) is my first iteration of a personal finance app built with Next.js.

## Tech Stack
- Next.js (Pages Router)
- React
- NextAuth (authentication)
- MongoDB (Mongoose)
- i18n (next-i18next)
- Charts (recharts)
- Tests (Jest + Testing Library)
- UI: styled-components, react-toastify
